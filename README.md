# İsim Şehir 🔤✍️

Klasik İsim Şehir oyunu: harfi çevir, parmağınla yaz, ilk sen **STOP** de!

- 10 kişiye kadar, herkes kendi telefonundan (oda kodu) ya da botlara karşı
- El yazısı tanıma (Android: Google ML Kit, Türkçe)
- Otomatik puan tablosu, oylama, emoji tepkileri, ödüller

Web sürümü: https://ahmetercikan.github.io/isimo/

## Geliştirme

```
npm install
npm run dev        # http://localhost:5290
npm test
npm run android:apk
```
